# Feature index

`index.yaml` answers "where is it?": for each feature, the files, the collections or tables, and the flow doc.
`docs/` answers "why and how". The two work together:

| Docs | Feature index |
| --- | --- |
| Meaning: why and how | Navigation: where and what |
| Prose, one file per flow | Pointers, one entry per feature |
| Broad understanding | Scoped exploration |

Maintained by the post-commit hook (`scripts/update-docs.sh`). Review its `docs: update` commits.
